# ACQ Smarthome · Sổ việc

Ứng dụng web (PWA) quản lý việc, kho, thu chi, hiệu suất KTV và phiếu xác nhận hoàn thành.

- `index.html` – toàn bộ ứng dụng
- `config.js` – khóa kết nối Supabase + khóa công khai VAPID
- `schema.sql` – lược đồ CSDL, phân quyền, trigger
- `supabase/functions/send-push` – hàm gửi thông báo đẩy
- `sw.js`, `manifest.json`, `icon*` – cài như app, tự cập nhật

Xem `HUONG-DAN.md` để triển khai.
